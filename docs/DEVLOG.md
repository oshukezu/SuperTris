# SuperTris 開發工作日誌 (Development Log)

---

### [2026-09-04] 雙人同方塊鏡像同步、P1開局握手流程與首頁紅白機選單升級
- **雙人同方塊鏡像同步 (Shared Piece Mirroring)**：
  - P1 房主為唯一方塊時間與生成源，即時透過 Realtime 廣播當前方塊坐標與形狀（`sync_piece`）以及 `nextPiece`。
  - P2 本地停止獨立下落與生成，100% 鏡像渲染 P1 的方塊，P2 的旋轉與下滑手勢發送給 P1 執行後立即回傳，雙方 100% 操控完全同一個方塊。
- **雙人連線開局握手流程 (Ready Handshake)**：
  - P2 輸入代碼加入後，P2 畫面提示：`等待 1p 開始` / `Waiting for host`。
  - P1 畫面即時響應為綠色 `隊友已連線` / `Partner connected`，並出現金色純文字按鈕 **`開始遊戲` / `Start Game`**。
  - P1 點擊開始遊戲後，廣播 `start_coop_game`，雙端彈窗同步關閉，平穩進入雙人合作。
- **首頁 1P / 2P 紅白機經典選單**：
  - 單一動態 🍄 蘑菇游標，未選中項為透明佔位。
  - 支援鍵盤 **↑ / ↓ / W / S** 上下切換選中狀態，伴隨音效。
  - 點擊或按下 **Enter / Space** 時，選中項原地閃爍 4 次（約 0.6s），播放開局音效後進入遊戲或打開彈窗。
- **單檔 400 行限制維護**：
  - 全專案單檔行數維持在 **8~397 行**，完全符合 400 行上限。
