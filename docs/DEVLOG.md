### [2026-09-03] 雙人模式 P2 暫停禁用與 P1 PAUSE 專屬提示
- **P2 暫停按鈕禁用**：
  - 在 2P 模式下，P2（加入者）的 `SET` 選單內的 `PAUSE` 按鈕呈現暗灰色禁用狀態（`opacity: 0.5; pointer-events: none;`），由 P1 房主統一掌管暫停權限。
- **P1 暫停時雙端專屬提示**：
  - P1 畫面提示：`PAUSED (TAP ANYWHERE TO RESUME)`（點擊任意處恢復）。
  - P2 畫面提示：`P1 PAUSED (WAITING FOR P1...)`（清晰告知 P1 暫停中，等待房主恢復）。
  - 雙人模式下點擊全螢幕解除暫停僅由 P1 響應並即時廣播雙端同步。
