# SuperTris 開發工作日誌 (Development Log)

---

### [2026-09-04] 3大修復(排行榜/雙人開局/消行震塌)與4大新機制(20行升級/全清獎勵/Ghost隱藏/1985瑪利歐動畫)
- **三大 Bug 徹底根除**：
  1. **排行榜顯示修復**：在 `js/supabase-service.js` 補齊 `isConfigured()` 與 `getTopScores` 支援，修復函式名稱不一致導致的拋錯，本地/雲端榜單 100% 秒開。
  2. **雙人開局連線修復**：修復 `js/multiplayer.js` 中的 `isAvailable()` 呼叫，確保雙端 Realtime 握手成功後立即平穩觸發 `startNewGame('coop')` 開局。
  3. **消行全盤震塌修復**：修正 `src/tetris.js`，一般消行嚴格遵循俄羅斯方塊標準平移，徹底關閉常態性全局重力沉降，僅在 ⭐ 星星或 💥 炸彈時才局部重力填補。
- **四大全新遊戲機制**：
  1. **每消 20 行升級速度**：在 `src/score.js` 調整升級計算（`Math.floor(this.lines / 20) + 1`），升速門檻放寬為 20 行/級。
  2. **All Clear 全清獎勵**：棋盤全空時觸發專屬獎勵（**+3,000 分 & +💎5**）並跳出全清 Toast。
  3. **Ghost 落點投影高階隱藏**：LV 1~2 顯示 Ghost 落點，**LV 3（消 40 行）起自動隱藏**。
  4. **1985 瑪利歐金幣拋跳與道具冒出動畫**：
     - 金幣：消行時在原磚塊位置向上拋射彈跳旋轉下落。
     - 道具：問號方塊消掉時，道具圖示從頂部緩慢向上冒出（0.5 秒），冒出後才觸發效果與 Toast。
- **單檔 400 行限制審查**：
  - 全專案單檔行數維持在 8~398 行，完全符合 400 行上限。
