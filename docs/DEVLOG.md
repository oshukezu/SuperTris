### [2026-09-03] 2P 房間彈窗「產生代碼 / 輸入代碼」極簡一步到位（零 Emoji、單行不換行）
- **2P 彈窗極簡一體化設計**：
  - 點擊 `2P player` 打開彈窗：上半部立即自動隨機生成 4 碼（如 `5824`）以 P1 (Host) 身份等待隊友。
  - 下半部直接提供「輸入代碼」輸入欄與「加入房間」按鈕，想當 P2 的玩家填碼一鍵切換加入。
  - 遵循全域規範：全站 UI 文字零 Emoji、單行不換行、無中括號，精確採用繁中「產生代碼 / 輸入代碼」、英文「Share code / Enter code」。
  - 點擊右上角 `X` 關閉彈窗時立即退訂頻道，杜絕連線資源殘留。

### [2026-09-03] 雙人模式 P2 暫停禁用與 P1 PAUSE 專屬提示
- **P2 暫停按鈕禁用**：
  - 在 2P 模式下，P2 的 `SET` 選單內的 `PAUSE` 按鈕呈現暗灰色禁用狀態（`opacity: 0.5; pointer-events: none;`），由 P1 房主統一掌管暫停權限。
- **P1 暫停時雙端專屬提示**：
  - P1 畫面提示：`PAUSED (TAP ANYWHERE TO RESUME)`。
  - P2 畫面提示：`P1 PAUSED (WAITING FOR P1...)`。

### [2026-09-03] 頂部第二排四欄等寬垂直對齊(LIFE與LINES對調)與SET按鈕純文字化
